# 模拟售后规则 v0.1

## 1. 说明

本项目售后规则全部为模拟规则。

当前文档只定义规则结构和验证维度，不自行编造真实电商平台的退款、退货或换货政策。

具体订单是否满足售后申请条件，由 FastAPI 后端根据：

- 当前登录用户
- 订单
- 订单状态
- 商品类型
- 时间
- 规则版本
- 用户提交的信息

进行确定性判断。

Dify 只负责收集参数、调用接口和展示结果，不负责最终业务判断。

## 2. 预检查结果

售后预检查统一返回以下业务结果之一：

- 可提交审核
- 需补充信息
- 需人工复核

预检查通过不代表已经退款或完成售后。

本项目最终只创建待审核工单，不执行真实退款、支付或物流操作。

## 3. 规则版本

第一版规则版本：

policy_version: v1

规则文件与售后政策知识库内容必须保持同一版本。

后续规则调整时，不直接覆盖旧版本，需要保留版本记录。

## 5. 后续实现要求

阶段 4 实现售后功能时：

1. 使用 Python 编写规则预检查。
2. 不让 LLM 决定最终规则结果。
3. 预检查结果需要记录 policy_version。
4. 创建工单前先展示申请摘要。
5. 用户明确确认后才能创建工单。
6. 工单创建必须支持幂等。
7. 工单创建失败时不能返回虚构工单号。
